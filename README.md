# TicTacToe
This is a web-based 2-player Tic Tac Toe game built with HTML, CSS, and JavaScript. Players take turns clicking on a 3×3 grid to place their symbol (X or O). The game detects wins, draws, and includes a reset button to start a new game. Hovering over empty cells shows a faded preview (ghost) of the current player's move, making it more intuitive.
